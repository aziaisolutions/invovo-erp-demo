Documentation

Welcome to the official technical documentation for Invovo ERP SaaS Edition. This guide will walk you through the entire deployment and customization process.

Prerequisites

  • Node.js: v18.0 or higher installed.
  • Supabase: A free account at supabase.com.

Local Installation

Extract the downloaded ZIP file, open your terminal in the root directory, and run the following commands:

npm install
npm run dev

Supabase Database Setup

Invovo ERP uses Supabase (PostgreSQL) for its backend. We have included a complete automated schema script for you.

  1. Create a new project in your Supabase Dashboard.
  2. Navigate to the SQL Editor from the left sidebar.
  3. Click New Query.
  4. Open the supabase_schema.sql file located in the root of your project folder.
  5. Copy the entire content, paste it into the SQL Editor, and hit Run.
Important: After running the schema, you must manually create a User from the Supabase Authentication dashboard so you can log into the app!

(Optional) Dummy Data: If you want to populate your store with a dummy catalog and customers, run the supabase_seed.sql file after the schema. Make sure to replace the placeholder User UUID with your actual Auth UUID.

Environment Variables

Your React application needs to connect to Supabase. Find the .env.example file in your project root and rename it to .env.local.

VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGci...
VITE_DEFAULT_CURRENCY=USD

You can find your URL and Anon Key in your Supabase Dashboard under Project Settings -> API.

Customization & Branding

Invovo ERP allows you to configure your marketplace currency and default branding without touching core React logic.

Open src/config/appConfig.js in your code editor:

export const APP_CONFIG = {
  appName: 'Invovo ERP',
  companyName: 'Your SaaS Brand',
  defaultCurrency: import.meta.env.VITE_DEFAULT_CURRENCY || 'PKR',
  supportedCurrencies: {
    PKR: { symbol: 'Rs.' },
    USD: { symbol: '$' },
    EUR: { symbol: '€' }
  }
};

To change the currency dynamically without code edits, simply add VITE_DEFAULT_CURRENCY=USD to your .env.local or Vercel settings!

Deployment (Production)

Since Invovo ERP is built with Vite, it can be hosted on any static hosting platform for free (e.g., Vercel, Netlify, Cloudflare Pages).

  1. Push your customized code to a private GitHub repository.
  2. Import the repository into Vercel or Netlify.
  3. Set the build command to npm run build and output to dist.
  4. CRITICAL: Add your VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY to the Environment Variables section in the Vercel/Netlify dashboard.
  5. Click Deploy. Your POS is now live worldwide!

FAQs & Troubleshooting

Q: I get a red "Setup Required" screen when I start the app.
A: This means your .env.local file is missing or named incorrectly, or you forgot to restart your terminal after creating it.

Q: I can't login with my user credentials!
A: Make sure you created the user via the Supabase Authentication Dashboard, and that you have successfully run the supabase_schema.sql which maps Auth users to Public Profiles.

Q: Does this work offline?
A: Yes. The POS utilizes PWA Service Workers to cache assets and allows local queuing of invoice data when the internet drops.
